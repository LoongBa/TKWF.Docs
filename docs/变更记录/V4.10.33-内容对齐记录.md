## 变更背景

`_TKWF` 自 v4.10.24（2026-09-15）以来发布 **v4.10.25 ~ v4.10.33** 共 9 个版本：

- **v4.10.25**（2026-09-15）：V5 破坏性变更收尾 F1-F5（ADR78 `InitializeAsync(IServiceProvider)` 断代升级，F1/F3 实证已完成）；xCodeGen 中枢化完成判定（ADR32 方案 A）+ dotnet tool 发布就绪（ADR77 商业许可 `PackageLicenseFile`）+ VEntity-Sql.md 静态产出（`VEntitySql.cshtml` 模板）+ sqlglot 否定落地
- **v4.10.26**（2026-09-16）：SignalNewJob 测试 flaky 根治（信号证明与终态等待分离）；D08 补 NuGet Trusted Publishing 迁移记录（OIDC 替代 NUGET_API_KEY）
- **v4.10.27**（2026-09-16）：**D20 分析服务 Stage 1 框架侧落地**——`TKW.Framework.Utility.Analytics` 核心（Loader/Validator/Options/三类异常）+ `TKWF.Ext.Analytics` 集成层 + flint 模板注册表快照 + tkwf-analytics-view skill；扩展双模式定案 DLL 模式；N5 FileManagement 用户级配额
- **v4.10.28**（2026-09-17）：SignalNewJob flaky 根治残留（SignalProveStartedCeiling 3s→5s + CI 测试串行逐项目 + Quartz fixture 就绪探测）
- **v4.10.29**（2026-09-18）：**贡献者机制 A+ 阶段 1**——`ContributorDescriptor` 四元组 + `Contributors` 单桥 + SG 接口判定骨架（Menu 先行）+ xCodeGen ContributorRegistry/ValidationChecker + CTRB001-003 预留
- **v4.10.30**（2026-09-18）：**贡献者机制 A+ 阶段 2**——旧桥转发 + SG 删 Menu override + ADR39 修订 + 扩展侧 ADR-Navigation-贡献者机制A+迁移（注：本版本未单独入 CHANGELOG）
- **v4.10.31**（2026-09-18）：**贡献者机制 A+ 阶段 3**——Permission/Feature 同模式批量迁移接口判定（PERM001 锁步）；G17B 错误处理表改接口表述；扩展测试基建修复（DLL 模式 NuGet 传递冲突 / FreeSql 传递失效 / StubsSource 拼接）
- **v4.10.32**（2026-09-18）：**贡献者机制 A+ 阶段 4（V5 破坏性清理）**——删旧 3 特性常量/旧 3 桥/Data 类/SG 旧分支；`CreateContributorInstances(targetKind)` 编译期实例化（消除 Activator 反射）；CTRB001-003 诊断码「预留」→「已实施」；A+ 4 阶段闭环
- **v4.10.33**（2026-09-19）：**i18n 国际化 Phase 1（ADR31 采纳）**——`_Framework/Localization/` 基础设施 + `IFrameworkLocalizer`/`IFrameworkCultureAccessor`/`ILocalizationResourceContributor` 三接口 + resx 内核（en + zh-CN satellite）+ `DomainException` 加性 MessageKey/MessageArgs + 错误码唯一事实权威收拢（`SYSTEM_SETUP_REQUIRED`/`INFRASTRUCTURE_OFFLINE` 入 ErrorCodes、REST 端 `EntityNotFoundException` DOMAIN_ERROR→NOT_FOUND）+ 10 枚举键化 + 校验/守卫消息键化（breaking：text-matcher）；D18A 全表刷新（W9-W11）+ Guard.cs 双向漂移门禁；扩展模块组通知与迁移说明

**文档体系**：v4.30 → **v4.33**（2026-09-19）——v4.31（D20 Stage 1 框架侧落地）/ v4.32（贡献者机制 A+ 阶段 1）/ v4.33（新增 `00-Onboarding-企业版源码交付-导航指南.md`）。D/G 编号无增减，无重编号。
