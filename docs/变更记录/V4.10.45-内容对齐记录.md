## 变更背景

`_TKWF` 自 v4.10.38（2026-09-30）以来发布 **v4.10.39 ~ v4.10.45** 共 7 个版本（均 2026-10-01）：

- **v4.10.39**：**分组聚合 API（F7，V5 候选转正）**——`FreeSqlQueryableExtensions` 增补 `GroupByAsync`/`GroupCountAsync` 三分组聚合方法（GROUP BY + ORDER BY + LIMIT 全下推，ADR15 决策 3 预埋落地）；扩展侧 AuditLogging V0.4.2 / SecurityLog V0.3.1 / Tagging V0.4.3 TopN SQL 下推
- **v4.10.40**：SG1a 空骨架早退点生成空壳 ProjectMetaContext（ADR85，消除 CS0103）+ 部署包 local-feed 机制（扩展侧方案 B）
- **v4.10.41**：**D19 AOT 三件套（ADR84 落地）**——JIT 为主 + 诚实标注策略（已标注点保证/未标注点不承诺）+ TrimAnalyzer 基线产出（新增 D19A 清单）；门控缺口 #2 OutboxSenderRegistered 已实现
- **v4.10.42**：D19 AOT 三件套复查补丁——LoggerMessage 补迁 12 文件 30 调用点（含 6 热路径 AOP 过滤器）+ `DomainUserJsonConverter.Write` 标注
- **v4.10.43**：**会话 JSON 注册表 API（ADR86）**——`SessionJsonTypeRegistry` 编译期闭集替换反射兜底（B1 烘焙缺省 + B2 消费方 SG opt-in + B3 内置源生成）+ `DomainUserJsonConverter.Read` 零反射命中路径 + StrictMode 硬失败
- **v4.10.44**：**会话 JSON 注册表 SG 生成（ADR86 偏离注记）**——`[SessionUserType]` 标记 + `SessionUserTypeGenerator`（SG1a）自动注册 + `TKWF_SG1a_SESS001-004` 诊断 4 个（D18A 登记）
- **v4.10.45**：**Web 装配钩子（ADR87，V5前收尾 #47）**——`TKWF.Domain.Web` 提供 `IWebExtension`（ConfigureServices 宿主注册 → ConfigureMiddleware `MiddlewareAnchor` 分桶 → ConfigureEndpoints）+ `UseWebExtensions` 消费方装配；与 Domain 扩展机制（D17 三钩子）正交零改动（领域自治边界 `TKWF_SG1b_WEBEXT_001` 门控）；新增 **D22（设计方案）/ G18（使用指南）** 编号文档；D17 P0 扩展模块 **11/11 全部落地**（PrintTemplates V0.2.0 最后一项）

**扩展侧**（`_TKWF.Extensions`，2026-10-01 批量落地）：

- **MFA V0.1.0**（多因素认证，`TKWF.Ext.MFA`）——第二因素验证服务：TOTP（RFC 6238 自研）+ SMS 双方法 + 挑战票据 + 恢复码 + 原子消费；**独立扩展零依赖**（不引 Authentication、不改主框架，登录编排归消费方）；3 ADR 落档 + Oracle 方案评审 PASS WITH CONDITIONS（11 条件全吸收）+ 实施 49+ 测试全绿
- **Authentication V0.1.0 → V0.2.0**——账号写契约 `IAuthAccountService`（影子账号 upsert/改密失效/停用，ADR 留档）+ E1 认证入口匿名面 `[AllowAnonymousFlag]` 5 接口 9 方法（负向边界锁 + AnonymousSurfaceTests 67/67）；tag Authentication/v0.2.0 已打
- **UserCenter V0.1.0 发布**——三 tag 批次（UserCenter.Abstractions/v0.1.0 + UserCenter/v0.1.0 + Authentication/v0.2.0），nuget.org 三包 listed 核验通过
- **Identity V0.4.0 / Notifications V0.5.0**——VEntity REST 直接暴露（`UserRoleViewQueryService`/`UserNotificationViewQueryService`，03 教学案例）
- **FileManagement V0.3.0**——用户级配额（OwnerId 归属维度）+ 并发上传竞态加固（UX 约束败者重查按内容决策）
- **OrganizationUnit V0.2.0 / DataDictionary V0.2.0**——VEntity 化/下推（04 教学案例）
- **框架实战教学**（扩展仓 docs/框架实战教学/）——01-开篇 §3.5 消费方剪裁哲学新增
