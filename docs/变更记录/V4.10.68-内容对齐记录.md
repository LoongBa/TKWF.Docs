## 变更背景

`_TKWF` 自 v4.10.59（2026-10-05）以来发布 **v4.10.60 ~ v4.10.68** 共 9 个版本：

- **v4.10.60**（2026-10-06）：OAuth 2.0/OIDC 协议引擎 `TKWF.Utility.OAuthClient`（Oracle 双 PASS）+ V5 清单 #21 已实施
- **v4.10.61**（2026-10-06）：**E4 密钥管理抽象上提主框架（ADR96）**——5 项 API（`ISymmetricKeyProvider`/`FileSymmetricKeyProvider`/`DevKeyCache`/`AeadEncryptionUtil` byte[] 重载/`SymmetricKeyProviderKeys`）+ **keyed DI 首次引入** + 守卫工厂 AOP 端到端实证
- **v4.10.62**（2026-10-06）：`IDacQuerySurface` 数据访问表面判定接口 + **V5.0 前瞻立项 Iter-0 交付**（ADR97-102 固化台账：请求级 UoW/多 ORM 并存/扩展依赖版本声明/能力目录/多 DAC 注册契约）+ nuget-unlist workflow 参数化
- **v4.10.63**（2026-10-06）：OAuthClient 引擎 OIDC 增强（ADR103）——边界扩展与 client_credentials 新功能决策 + 跨服务身份传递基线（ADR102）
- **v4.10.64**（2026-10-06）：V5/Iter-1 请求级 UoW 上下文（ADR97 实施修正 C1-C3）+ D18A 诊断码登记
- **v4.10.65**（2026-10-06）：V5/Iter-4 M3 扩展依赖版本门控——`[TKWFExtensionDependency]` + SemVerUtil 比较器 + SG 编译期校验（ADR50 L58 兑现）
- **v4.10.66**（2026-10-07）：**表名别名机制一等公民化（ADR100）**——统一表名解析权威 + TABLE 门控族 4 码（`TKWF_SG1a_TABLE001-004`）+ 框架表前缀统一（扩展侧 52 实体 `TKWF_` 前缀，撞名处置追尾方全责）
- **v4.10.67**（2026-10-07）：`IRateLimitCheck` 点检查限流原语 R1（ADR104，Utility 收纳边界）——响应扩展组转达（AuthCenter 身份域频控）
- **v4.10.68**（2026-10-07）：密钥强度调整（转告回复闭环）——组件指南 §7 安全基线 + 适配通知

**扩展侧**（`_TKWF.Extensions`，2026-10-05 ~ 10-07 批量落地）：

- **Authentication → AuthCenter 归层改名**（V0.6.0 → V0.9.1）：2026-10-06 `Authentication` 全面归层为 `AuthCenter`（含旧路径删除配对提交）；V0.6.0 归层 + 内建 6 标准对内端点 + 登录门面 `LoginResult` + 配置分层 `TKWF:AuthCenter:Web`；V0.7.0 E4 密钥管理（CPM 4.10.61 ADR96）；V0.8.0 认证 API 补全（verify/grants/smsverify + 票据绑定闭环）；V0.9.0 身份域重构与密码能力（`SecurePassword` 协议 + 密码策略面 + 账号冻结 + `IRateLimitCheck` 频控 + 找回多通道）；V0.9.1 Email 找回 6 项裁定（模板 Options + TTL 配置化 + 冻结找回互斥 + Email 独立频控）
