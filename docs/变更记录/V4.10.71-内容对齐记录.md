## 变更背景

`_TKWF` 自 v4.10.68（2026-10-07）以来发布 **v4.10.69 ~ v4.10.71** 共 3 个版本：

- **v4.10.69**（2026-10-10）：`SymmetricKeyProviderKeys` 并入 **AuthSurface** 键（ADR96 边界兑现——C11 第 4 扩展，响应扩展组转达《SymmetricKeyProviderKeys申报并入AuthSurface键》）+ 发布纪律新增（tag 后本地部署优先 / CI 发布后不必等 NuGet 传播）
- **v4.10.70**（2026-10-10）：`SymmetricKeyProviderKeys` 并入 **TrustCenter** 键（ADR96 边界兑现——C11 第 5 扩展，响应扩展组转达《SymmetricKeyProviderKeys申报并入TrustCenter键》）
- **v4.10.71**（2026-10-11）：**OAuth 资源服务器中间件 + JWKS ES256（Iter-6 框架侧交付）**——OAuth 资源服务器中间件落地 + JWKS ES256 + **ADR102 生效**（跨服务身份传递基线：🔴提议→✅生效）；扩展组统一适配通知（A1 AuthCenter aud 契约 / A2 装配序契约 / A3 Federation ES256 验签路径 / A4 一步装配形态 / A5 WWW-Authenticate；CPM 联动前提）；总纲 §八 Iter-6 完成态 + §十验收勾选

**扩展侧**（`_TKWF.Extensions`，2026-10-08 ~ 10-11 批量落地）：

- **认证体系三层架构定局**：**AuthCenter（身份）→ TrustCenter（信任）→ Federation（连接）**——2026-10-09 TrustCenter 自 Federation 剥离（纯信任内核：`SsoClientEntity` 应用注册 + token2 ES256 独立密钥域 + accesscode + **安全数据投递增强**（Payload AES-GCM 密文落库））；Federation 重定位为**对外连接层壳**（平台 IdP 连接 + `/sso/*` 端点 + 多通道设施 `IChannelRegistry` 系列 + `FederationWebExtension`）；契约归 `TrustCenter.Abstractions`；**TrustCenter V0.1.0 → V0.2.0**、**Federation V0.2.0 → V0.6.0** 批量迭代 + 三 tag 批次发布
- **Federation 平台网关系列**（多通道联邦 v0.3.0 + 后续迭代）：Oidc/Google/Microsoft V0.2.2、DingTalk/WeCom/WeChat/QQ V0.3.0、**Alipay 新增**（N4，出站-only + RSA2 双向签名，v0.1.0 → v0.2.0）；ChannelAlias 对外别名双键（Phase 3）
- **AuthCenter V0.9.1 → V0.9.2 → V0.9.3**：外部 IdP 桥接（T5，`IExternalIdpLoginService` 借道 Federation——微信双源 Provider/ApiClient/Login 归层）；AuthCenter.Abstractions V0.1.0；OAuth 资源服务器中间件适配（v4.10.71）
- **AuthSurface V0.2.0**：UserCenter DTO 归主包承接（C11 第 4 扩展）；**UserCenter 完整删除退役**（2026-10-09 收尾：行删除 + 残留引用中性化 + 转达框架组）
- **MFA V0.2.1**：IRateLimitCheck 迁移（删 MfaRateLimiter 改 DI 注入 IRateLimitCheck，key 规范化 `{policy}:{partitionBy}:{subject}`）
- **RateLimiting V0.3.0**：点检查原语 DB Provider（`SqlCountRateLimitCheck`——`TKWF_RateLimitCounter` 计数表 + ADR89 CAS 原子递增 + 接线型 ctor 帧内守卫工厂解析）
- **Federation 多通道联邦**：v0.1.0 开发方案 → v0.3.0 发布（多通道能力文档同步 Phase 2 DB 动态权威 + 使用指南 §3.5a/3.5b §3.5c + 故障排查专项）
