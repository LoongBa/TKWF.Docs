## 变更背景

`_TKWF` 自 v4.10.71（2026-10-11）以来发布 **v4.10.72 ~ v4.10.74** 共 3 个版本：

- **v4.10.72**（2026-10-11）：**微服务前瞻收尾**（ADR105）——服务间认证形态基线（mTLS 与 TokenExchange 归层）+ 独立服务范式样例 + Outbox 跨进程验证 + DockerDaemonGuard 泛化（PgContainerGuard → DockerDaemonGuard）
- **v4.10.73**（2026-10-14）：**表现层页面装配（ADR106）**——PageAssembly 门面投影 + Blazor 脚手架 + AuthFlow 参数化；新增 **D23-表现层页面装配-设计方案** + **G19-表现层页面装配-使用指南** 编号文档；D18A 登记 **PAGE 门控族 `TKWF_SG1b_PAGE001-004`**（页面贡献者归属/可实例化/路由冲突/资源声明）；⚠️ IPageContributor 接口本体（外部表现层 Abstractions 包）+ TS codegen + @tkwf/reference-components 待实现（文档描述目标态）
- **v4.10.74**（2026-10-14）：**外部身份联邦与会话绑定守卫（ADR107）**——外部身份联邦框架机制（D1-D5）

**扩展侧**（`_TKWF.Extensions`，2026-10-11 ~ 10-14 批量落地）：

- **Federation V0.6.0 → V0.7.0 → V0.7.1**：**V0.7.0 破坏性路由变更**——对外路由命名空间 `/sso/*` → `/feberation/{platform}/*` + 平台段 + B 守卫 + event 缺陷修复（消费方三方三处 URL 适配通知）+ 键形态最佳实践（ChannelId 建议 uuid / Alias 建议必填，2026-10-10 用户裁定）；**V0.7.1 外部身份联邦 Phase1 E1-E3 适配**（框架 v4.10.74 ADR107 配套）
- **AuthCenter V0.9.4**：外部身份联邦 Phase1 E1-E3 适配（框架 v4.10.74 ADR107 配套）
- **TrustCenter V0.2.1 + TrustCenter.Abstractions V0.2.1**：外部身份联邦 Phase1 E1-E3 适配
- **Federation.WeChat V0.3.1**：验签纵深防御（外部身份联邦审核报告 Oracle P2×3 遗留处理）
- **CPM lockstep**：v4.10.71 → v4.10.72 全量 lockstep（OAuth 资源服务器 + 微服务前瞻收尾 + 容器测试基座）
