## 变更背景

`_TKWF` 自 v4.10.74（2026-10-14）发布 **v4.10.76 ~ v4.10.85**（v4.10.75 无 tag；v4.10.76-81 连续迭代，v4.10.82 起端点到扩展侧化），期间关键变化：

- **v4.10.76（ADR108）**：HttpAuth 匿名端点排除机制——扩展声明匿名端点即放行（消费方零配置）；HttpAuthentication 锚点移至 UseRouting 后
- **v4.10.77-79（ADR109/110）**：D3 票据契约演进（TicketRedeemContext）+ 票据 CAS + MaxRedeems 有界配额——AuthCenter 扩展侧
- **v4.10.82（F13 破坏性迁移, ADR112）**：`IWebExtension.ConfigureEndpoints(builder)` → `DeclareEndpoints(IExtensionEndpointRegistry)`（不留 Obsolete）；注册表成为全仓唯一端点登记通道；`MapGenerated<TFacade>()`/`MapInfrastructure(EndpointKind)` 闭枚举；Oracle C+E 协议适配通道（`IProtocolEndpointBuilder`）
- **v4.10.83/84**：端点注册表收紧为"仅 Web 扩展生成"；门控按共享框架程序集精确名单判定（非 Web 扩展 CI CS0234 根治）
- **v4.10.85**：扩展端点装配前缀显式空串语义（两级：base 跳过第一级 / 模块前缀清除）+ 8 前缀用例
- **v4.10.86（ADR111，未打 tag 并入）**：DevPage 框架头注册（Development + UseWebExceptionMiddleware 自动挂载）+ `DevRethrowUnknownExceptions` 未知异常环境分流

本站同步采用方式：README 版本表补 11 行（76-86 含未打 tag 的 86，标注"内容并入"）；扩展版本列以扩展仓 `git tag` 实测回填（AuthCenter 0.10.1 / Federation 0.15.0 / TrustCenter 0.3.3 / Federation.WeChat 0.16.1 等 15 项，usage.md 范围上限 7 项）；F13 与 ADR108/111 属框架机制变化，站点扩展文章补 Web 装配钩子章节并在 web.md/rest-minimal-api.md 同步。
