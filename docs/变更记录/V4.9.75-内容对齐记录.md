## 变更背景

`_TKWF` 自 v4.9.68（2026-08-27）以来发布 v4.9.69-75 七个版本，全部围绕**扩展机制**：

- **v4.9.69**（2026-08-28）：RPC 响应携带事件侧信道（ADR33 阶段 2+3）——REST `X-TKWF-Events` 头 / GraphQL `extensions.tkwf.events`
- **v4.9.70**（2026-08-28）：统一运行时门控完整化（ADR35）+ 扩展机制 Phase 1 基座（ADR37）——`GateRules` 数据驱动规则集 + 扩展契约 + `FilterBuilder` 分层注册
- **v4.9.71**（2026-08-28）：扩展机制 Phase 2（ADR37）——三钩子接入启动流程 + 扩展清单 API + `IsEnabled` 按需启停
- **v4.9.72**（2026-08-28）：**Permissions 扩展落地**（ADR38）——首个 `TKWF.Ext.*` 业务扩展包
- **v4.9.73**（2026-08-28）：扩展机制遗留收尾——修复 SG 特征门控扫描 `Contains` 逻辑反转（V4.9.70 静默缺陷）+ SG 生成代码真实消费者编译验证
- **v4.9.74**（2026-08-28）：**Navigation 扩展落地**（ADR39）——菜单扩展包 + `IMenuManager` 权限过滤
- **v4.9.75**（2026-08-28）：**扩展机制最终收尾**——B1 `SourceExtension`（禁用扩展跳过 Warning 级门控）+ A1 DI 全图验证（`TKWF_DI001`）+ C1 `FreeSqlPermissionStore` 权限持久化 + A2 能力引用机制正式废弃（ADR37 决策 5）+ F1 TPA 引用缓存

> v4.9.70-74 的内容同步已在先前提交分批完成（`3c45b2f` 扩展 E1/E2 + `9ae5fab` D17/G17A/G17B + `87ee26a` 深度优化 + `0f7c05e` 扩展系列文件夹重构）；本轮补齐 v4.9.75 语义变更与版本号，并完成自 v4.9.61 以来首次 tag。
